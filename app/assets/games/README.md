# Visuels des jeux (page Game)

Dépose ici les images des deux grandes cartes de la page d'ouverture :

- `ets2.jpg` : Euro Truck Simulator 2
- `ats.jpg` : American Truck Simulator

Format conseillé : JPG paysage, 1600 × 1000 px minimum, sujet plutôt en haut (le bas de l'image est assombri pour le texte).
Utilise uniquement des images dont tu as les droits (tes propres captures du jeu, par exemple).

Sans fichier, l'appli affiche une illustration intégrée. Aucun code à modifier : l'image est prise automatiquement.
