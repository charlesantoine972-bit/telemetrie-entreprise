Guide de démarrage rapide
1. Ouvre l'appli : elle installe toute seule le plugin dans le jeu (vérifie dans Options).
2. Clique sur Lancer le jeu. Au premier lancement, le jeu affiche un message sur les « fonctions SDK avancées » : clique sur OK.
3. Roule : la page Télémétrie se remplit en direct, et tes missions s'enregistrent dans Ma carrière.
4. Règle tes préférences (seuil réel / course, type de véhicule) dans Options.
Prochains événements
Le calendrier des convois et événements de ton entreprise arrive avec la partie Entreprise.
