    Console de développement

    Active le mode développeur du jeu. Une fois activé, tu as accès à :

    • La console : touche ² sur un clavier AZERTY (~ en QWERTY) pour taper des commandes.
    • La caméra libre : touche 0 (rangée du haut) pour détacher la caméra et te déplacer librement autour du camion, idéal pour les captures d'écran.
    • Quelques commandes utiles :
      • g_set_time 12 : régler l'heure (ici midi) ;
      • g_set_weather 0 ou 1 : temps sec ou pluie ;
      • warp 2 : accélérer le temps (warp 1 pour revenir à la normale) ;
      • g_traffic 0 à 10 : densité du trafic ;
      • g_minicons 0 : masquer les petites icônes de la carte.

    Solo uniquement. Le jeu doit être fermé pour changer ce réglage : il le réécrit en quittant. Une copie de ton fichier de configuration est faite avant chaque changement. Les commandes peuvent changer d'une version du jeu à l'autre.

    MARKETPLACE · CRÉER

    Créer une livrée

    Une livrée, c'est la peinture de ton entreprise sur un camion, un car ou une remorque. Voici les grandes étapes ; le tutoriel détaillé et la publication dans la Marketplace arriveront avec les comptes.

    ÉTAPE 1

    Choisir le modèle

    Pars du gabarit de peinture (« template ») du véhicule : une image à plat de la cabine ou de la remorque, à peindre.

    ÉTAPE 2

    Dessiner

    Peins le gabarit dans un logiciel d'image (Photoshop, GIMP, Krita…) avec les couleurs et le logo de ton entreprise.

    ÉTAPE 3

    Convertir

    Exporte l'image dans le format de texture du jeu, puis crée les petits fichiers qui la déclarent comme peinture.

    ÉTAPE 4

    Empaqueter et tester

    Regroupe le tout en mod (.scs), place-le dans ton dossier de mods, active-le dans le jeu et vérifie le rendu.

    BIENTÔT

          Mode d’affichage du jeu

          Le bandeau se pose par-dessus la fenêtre du jeu. Il est visible si le jeu est en plein écran fenêtré (fenêtre sans bordures). En plein écran « exclusif », le jeu passe devant et le bandeau ne se voit pas. Si tu ne le vois pas en roulant, passe le jeu en fenêtré sans bordures dans ses options graphiques. Le bandeau ne bloque jamais la souris ni le clavier.
